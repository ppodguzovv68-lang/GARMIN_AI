# Архитектура

Краткое описание будущей архитектуры проекта.

## Garmin import

Импорт тренировок из Garmin: FIT/GPX/TCX файлы, валидация и нормализация данных.

## storage

Хранение данных в SQLite: тренировки, расчётные метрики, настройки пользователя.

## analytics

Расчёт нагрузки, восстановления и готовности на основе импортированных тренировок.

## planner

Формирование тренировочного плана и рекомендаций на основе аналитики.

## local AI

Локальная LLM через Ollama: анализ данных, объяснения и рекомендации.

## web UI

Веб-интерфейс: сначала простой HTML внутри FastAPI, позже отдельный frontend на React/Next.js.
